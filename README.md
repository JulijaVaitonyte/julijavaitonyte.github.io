# Julija Vaitonytė — personal website

Upload the contents of this ZIP to your GitHub repository, with index.html at the repository root and the assets folder beside it. Do not upload only the ZIP file.

Enable GitHub Pages for the branch and root folder containing these files. No build step or dependencies are required.

To preview locally, open index.html in a browser.

Edit page text and links in script.js and colors/layout in style.css. Use American English throughout. The CV and all photos are included. Project details and teaching content remain placeholders; the Media page reserves space for speaking photos.
